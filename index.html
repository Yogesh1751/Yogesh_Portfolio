My Best Projects

Smart Street Light Monitoring

Developed a LoRa-based smart monitoring system for detecting faults in street lights and locating them using GPS coordinates. The system detects parameters like voltage/current drop or open circuit faults and transmits the data to a central dashboard. By integrating Google Maps API, maintenance teams can visualize exact fault locations for timely repair.
Technologies Used: LoRa RA-02, NodeMCU (ESP8266), GPS Module (NEO-6M), Google Maps API, Arduino IDE, HTML/CSS.
Features: Real-time fault detection, GPS-based location tracking, Long-range communication, Low power.

Online Shopping App

A responsive e-commerce frontend developed using HTML, CSS, and JavaScript. It simulates a shopping platform with product cards, cart management, price calculation, and filtering options.
Technologies Used: HTML5, CSS3, JavaScript, LocalStorage, Media Queries.
Features: Add-to-cart & remove, product filtering, price summary, responsive UI.

Gas Detection System

An IoT-based gas monitoring solution using MQ-4, MQ-7, and MQ-135 sensors connected to ESP32. Data is sent via Wi-Fi to a XAMPP-based MySQL server and visualized using a PHP dashboard. Alerts are triggered when thresholds are exceeded.
Technologies Used: ESP32, MQ-series sensors, XAMPP, MySQL, PHP, Arduino IDE.
Features: Real-time monitoring, database logging, web dashboard, safety alerts.

GYM Application

A web-based Gym Management System that allows users to register, track workouts, and view schedules. Trainers can assign routines and manage members. Built using React and Firebase.
Technologies Used: React.js, Firebase, Firestore, Tailwind CSS.
Features: Member & trainer login, schedule management, responsive design, cloud integration.
